Watch for model downloads on supported sites. Turn this off to capture only from the toolbar popup.
An extension cannot read a file off your disk, so the download has to be fetched a second time to reach YASTL. Copy lets your normal download finish and fetches its own copy — you keep the file whatever happens, at the cost of downloading twice. Some sites issue links that only work once, and on those the second fetch fails; Intercept cancels the browser's download so the link is spent exactly once, but if the capture then fails you will need to click Download again.

About the token

The token is a shared secret sent with every capture. Over plain http:// on your LAN it is visible to anything already watching that network — it stops a random web page writing into your library, not a determined attacker on your own wire. Rotate it in YASTL Settings to revoke a browser that has it.
